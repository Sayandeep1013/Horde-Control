# UI Pass - FAILURE POINTS

## Predetermined

| ID | Risk | Mitigation |
| --- | --- | --- |
| UP-P1 | A restyle silently changes behaviour a test reads (node names, label text, style getters, sizes) | Implementers read the covering tests first; existing tests are never edited; full suite compared against the baseline |
| UP-P2 | Parallel implementers collide in one worktree | Disjoint file ownership per package; palette and theme are read-only to implementers; one suite at a time, never the whole folder |
| UP-P3 | Cosmetic motion re-times input, or leaves a closed surface visible | Motion animates visual-only properties; hide is immediate; tweens are bare `create_tween()` guarded by `is_inside_tree()` |
| UP-P4 | The subagent ask-gate does not intercept subagents (Phase 00 F-06) | Every delegation carries the worktree-only, no-delete, no-export, no `run_project`/`game_*` constraints in `BRIEF.md` |
| UP-P5 | A new font lacks the accented glyphs pseudo-localization renders | Pixelify Sans chosen for Latin Extended coverage; a pseudo-localized screenshot set is part of verification |
| UP-P6 | Interfering with agents working in `D:\Gamedev` | Separate worktree and branch; strict write allow-list; out-of-scope needs go to `HANDOFF.md` |
