# Project-made audio

All files under `assets/audio/sfx/` are generated by `tools/audio/make_sfx.py` (decision D180). No third-party samples are used. The script is pure Python standard library (`wave`, `struct`, `math`, `random`) and deterministic: each cue uses `random.Random(seed)`.

Regenerate: `python tools/audio/make_sfx.py` from the repository root. Analyse: `python tools/audio/make_sfx.py --analyse`.

Format: 44.1 kHz, mono, 16-bit PCM WAV, peak-normalised to -3 dBFS with short fades.
